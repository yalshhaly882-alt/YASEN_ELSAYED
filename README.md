# Yasoo — Portfolio

موقع شخصي لـ **ياسين السيد أبو حجازي (Yasoo)**.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيق
- `script.js` — الأنيميشن والتفاعلات
- `images/` — كل الصور المستخدمة في الموقع

## رفعه على GitHub Pages
1. اعمل ريبو جديد وارفع كل محتويات الفولدر (بما فيها فولدر `images`) في الروت.
2. من Settings → Pages → Source اختار `main` والروت `/`.
3. هتاخد رابط زي: `https://<username>.github.io/<repo-name>/`
