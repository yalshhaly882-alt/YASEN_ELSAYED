# Yasoo — Portfolio (مع لوحة تحكم)

موقع شخصي لـ **ياسين السيد أبو حجازي (Yasoo)** — كل المحتوى (نصوص وصور) متخزّن في ملف واحد `content.json`، والموقع بيقرأه ويعرضه. ده اللي بيخلي التعديل سهل من غير ما تلمس كود.

## الملفات
- `index.html` — الموقع نفسه (بيعرض المحتوى من `content.json`)
- `style.css` — التنسيق
- `script.js` — بيقرأ `content.json` ويبني الصفحة منه
- `content.json` — **كل** محتوى الموقع (الاسم، الصور، النصوص، الروابط...) في مكان واحد
- `admin.html` + `admin.js` — **لوحة التحكم** لتعديل المحتوى بواجهة سهلة

## إزاي تستخدم لوحة التحكم
1. افتح `admin.html` في المتصفح (بعد رفع الموقع، أو حتى محليًا على جهازك).
2. هيطلب منك **كلمة سر** — كلمة السر الافتراضية هي: `yasoo2026`
   (لتغييرها: افتح ملف `admin.html` بأي محرر نصوص، دوّر على السطر اللي فيه `ADMIN_PASSWORD = "yasoo2026"` وغيّر القيمة).
3. عدّل أي حاجة عايزها — نصوص، صور (اضغط "غيّر الصورة")، أضف/احذف عناصر في الجاليري أو الكروت.
4. اضغط **"حفظ ومعاينة محلي"** عشان تشوف شكل التعديلات فورًا (بتتحفظ في المتصفح بتاعك بس، مش على الإنترنت لسه).
5. اضغط **"افتح الموقع"** عشان تشوف المعاينة.
6. لما تكون مبسوط بالنتيجة، اضغط **"تحميل content.json"** — ده هيديك الملف المحدث.
7. ارفع الملف ده بدل القديم في مستودع GitHub بتاعك (أو أي استضافة) وادفعه (commit & push) — وقتها التعديلات هتظهر لكل الزوار.

> ⚠️ **مهم:** كلمة السر دي مجرد رادع بسيط لأي حد يفتح الرابط بالصدفة — مش حماية حقيقية 100%، لأن أي حد يقدر يفتح "عرض المصدر" (View Source) للصفحة ويشوفها. الحماية الحقيقية هنا هي إن `admin.html` مش متربوط بأي لينك في الموقع نفسه، يعني محدش هيوصله أصلاً غير لو عنده الرابط بالظبط. متشاركش رابط `admin.html` مع حد متثقش فيه.

> ⚠️ لوحة التحكم بتحفظ "معاينة" في متصفحك بس، لأن الموقع static ومفيهوش سيرفر أو قاعدة بيانات. الخطوة الوحيدة اللي بتنشر التعديل لكل الناس هي إنك ترفع `content.json` الجديد على الاستضافة.

## رفعه على GitHub Pages
1. اعمل ريبو جديد وارفع كل الملفات (`index.html`, `style.css`, `script.js`, `content.json`, `admin.html`, `admin.js`) في الروت.
2. من Settings → Pages → Source اختار `main` والروت `/`.
3. هتاخد رابط زي: `https://<username>.github.io/<repo-name>/`
4. لوحة التحكم هتبقى متاحة على: `https://<username>.github.io/<repo-name>/admin.html`
